## 2. Sistema de Licenciamento por Dispositivo

Controle de **quantos celulares** podem usar o app Invec em cada cliente. O limite é definido pela Pontual no momento da emissão da licença.

### Como funciona

```
Pontual emite licença com max_dispositivos=2
         ↓
Aparelho 1 faz login → registrado (slot 1/2)
Aparelho 2 faz login → registrado (slot 2/2)
Aparelho 3 faz login → BLOQUEADO com mensagem de erro
         ↓
Admin remove aparelho 1 → slot liberado
Aparelho 3 faz login → registrado (slot 2/2) ✓
```

### Mudanças no gerador de licença

```
python gerar_licenca.py
Nome do cliente      : Loja ABC
CNPJ                 : 00.000.000/0001-00
Validade (meses)     : 12
ID da maquina        : [Enter]
Max dispositivos moveis: 3       ← campo novo
```

Se deixar em branco → sem limite de dispositivos.

### Banco de dados — nova tabela

```sql
DISPOSITIVOS_AUTORIZADOS
  ID               INTEGER (PK)
  DEVICE_ID        VARCHAR(128) UNIQUE  -- UUID gerado pelo celular
  NOME_DISPOSITIVO VARCHAR(200)          -- ex.: "Samsung Galaxy A54"
  PRIMEIRO_ACESSO  TIMESTAMP
  ULTIMO_ACESSO    TIMESTAMP
```

Criada automaticamente na primeira inicialização do servidor atualizado.

### API — novos endpoints

| Método | Endpoint | Acesso | Descrição |
|---|---|---|---|
| `GET` | `/admin/dispositivos` | Admin/MI | Lista dispositivos registrados |
| `DELETE` | `/admin/dispositivos/{id}` | Admin/MI | Remove dispositivo (libera slot) |

### App Android — mudanças

- **Login:** envia automaticamente `device_id` (UUID único por aparelho) e `device_name` (modelo do celular)
- **Erro de limite:** Dialog de alerta com mensagem clara ao invés de Toast — ex.: *"Limite de licença atingido (2 dispositivo(s) autorizado(s)). Contate o administrador para liberar um slot."*
- **Tela Dispositivos Autorizados:** acessível pelo menu ⋮ em Usuários Mobile (admin/MI). Mostra lista de aparelhos com data de cadastro e último acesso. Botão "Remover" com confirmação.
